# catch

「catch」は、割り込みに振り回されずに今の作業に戻れるようにするためのシンプルなメモ・タスク管理アプリです。

「一行で入れて、後でまとめて処理する」を実践するために設計されています。仕事や学習中に思いついたことをその場で溜め込み、必要なときに戻って整理できるようにします。

## 概要

日々の作業では、メール、Slack、会議、思いついたアイデアなどが次々と割り込みになります。
本アプリは、以下の考え方を支援します。

- 30秒で終わることはその場で処理する
- それ以外は「一行で箱に入れる」
- 今の作業に戻る
- まとめて整理する

これにより、頭の中を一時的に捨てて、作業の流れを保ちやすくします。

## こんな人に向いている

- 集中して作業しているときに割り込みが多い人
- Todo を紙やメモ帳に書くより、簡単に「一行登録」したい人
- 「すぐやるべきか」「後でやるか」を見極めたい人
- 仕事や研究の間に気になったことを後回しにしがちな人

## 主要機能

### 1. 受け止め箱

入力フォームに一行だけメモを入れると、未処理の箱に追加されます。

- その場で完結しないことは、すぐに箱へ
- 後で見直しをする
- 作業を中断しにくくする

### 2. タスク化

未処理のメモから「タスク化」を選ぶと、優先度を持つタスクとして扱えます。

- 右側の「タスクにした」一覧に表示
- 上下ボタンで順番を並べ替え可能
- 重要なものを先頭へ

### 3. 完了記録

タスクやメモを処理したあとに「済」を押すと、完了履歴に追加されます。

- 今日完了した件数を表示
- 直近30件を履歴として保持
- 実行したことを振り返りやすい

### 4. しおり（現在地）

画面上部にある「いま、ここ →」欄で、今一番集中している作業や次に戻るべき場所を記録できます。

- やることの文脈を残す
- 途中で迷ったときのコンテキストを補う
- 次の切り替えポイントを明確にする

### 5. 即断ルール

画面下部の「即断ルール」では、迷ったときに見る簡単な判断基準が記載されています。

- 30秒で終わるならその場で対応
- それ以外は一行で投げる
- 劇的に緊急な場合だけしおりを更新して対応
- 昼前と夕方に箱を空にする

## 使い方

1. 画面にある入力欄へ、一行で気になることを入力
2. 「+」ボタンを押して箱に入れる
3. 着手前の作業に戻る
4. 途中で整理したいときに「タスク化」または「済」を使う
5. 必要に応じて「しおり」を更新する

## 画面構成

- しおり: 次に戻るべき作業や現在地の記録
- 未処理: 今の箱に入ったメモ一覧
- タスクにした: 優先順で並ぶ実行候補
- 完了済み: 直近30件の処理履歴

## 技術仕様

- シングルページの静的Webアプリ
- HTML / CSS / JavaScript で構成
- バックエンド不要
- ブラウザの localStorage に状態を保存
- PWAとしてインストール可能

## ローカルでの利用

ブラウザで `index.html` を開くだけで利用できます。

また、ローカルサーバーを立てて表示することも可能です。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 制作思想

本アプリは「思考を外に出して、今の作業を保つ」ための仕組みです。

割り込みに対して即座にすべてを記憶しようとすると、脳が疲弊します。そこで、

- 一行で受け止める
- すぐ戻る
- 後で片づける

というルールを前提にしています。

これは、日々の作業を「忘れずに進める」ための最小限のセルフマネジメントです。
